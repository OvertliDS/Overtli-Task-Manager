# File Structure Knowledge Base

## Concurrent route state

| Path                                                  | Responsibility                                                                                               | Invariants                                                                                                                                                                         |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/core/session-scope.mjs`                          | Resolves explicit hook session/thread/conversation ids, environment ids, and stable hashed session keys.     | Explicit payload identity wins; environment fallback never selects another session.                                                                                                |
| `src/core/planner.mjs`                                | Conservatively preserves explicit outlines and exposes non-completable fallback review scaffolds.            | Major outline roots become gates, depth-two children become internal subtasks, deeper items become mini-steps; model owns semantic domain content.                                 |
| `src/core/source-context.mjs`                         | Normalizes bounded typed/pasted, structured, attachment/OCR, and visual prompt sources.                      | Entries are redacted, provenance/path/revision tagged, digest-addressed, append-only across steering, and bounded to the shared context budget.                                    |
| `src/core/manager.mjs`                                | Validates workspace/session scope and coordinates guarded lifecycle operations.                              | Legacy adoption is opt-in; contract review plus required evidence-backed subtask/mini-step descendants gate completion; summaries/export preserve hierarchy and source context.    |
| `src/storage/sqlite-store.mjs`                        | Probes/repairs the native binding and provides the durable concurrent WAL store.                             | Only genuine ABI mismatch may trigger one package-local locked rebuild; schema v4 enforces cascading child foreign keys and preserves a pre-migration recovery copy.               |
| `src/storage/store.mjs`                               | Selects explicit SQLite/JSON or automatic native-first storage.                                              | Explicit SQLite fails closed; `auto` may fall back to JSON after probe/repair failure without deleting or overwriting inactive SQLite state.                                       |
| `src/storage/json-store.mjs`                          | JSON fallback store.                                                                                         | Every mutation holds `state.lock`; stale locks older than 30 seconds may be recovered.                                                                                             |
| `src/core/renderer.mjs`                               | Writes canonical hierarchy/source snapshots, summaries, and the workspace index.                             | Session snapshots are authoritative and complete; top-level current files remain lightweight route pointers.                                                                       |
| `src/mcp/schemas.mjs`, `src/mcp/tools.mjs`            | Expose bounded three-tier route, context, progress, and evidence contracts to models.                        | Model supplies domain-specific gates/subtasks/mini-steps; exact IDs and recursive evidence gates are explicit in tool guidance.                                                    |
| `src/hooks/runner.mjs`                                | Resolves hook identity, appends prompt context, deduplicates invocations, and dispatches lifecycle handlers. | Hooks without session identity do not touch route state; substantive source revisions require model reconciliation; repeated Stop feedback/errors cannot create an unbounded loop. |
| `src/install/agent-block.mjs`                         | Builds and safely patches OTM's marker-delimited root `AGENTS.md` protocol.                                  | Preserves all non-OTM text; duplicate/incomplete markers fail closed; generated guidance defines accumulated-context review and the three-tier model/OTM ownership boundary.       |
| `AGENTS.md`                                           | Root repository guidance plus OTM's managed execution protocol.                                              | Repository guidance outside OTM markers is maintained manually; only the marker-delimited block is hook-managed.                                                                   |
| `src/cli/commands.mjs`                                | Exposes install, diagnostics, snapshots, cleanup, and maintenance.                                           | Session-sensitive read/clear commands accept `--session-id`; doctor/snapshot are read-only.                                                                                        |
| `.codex/overtli-task-manager/sessions/<session-key>/` | Runtime route state and session-owned scratch evidence.                                                      | Generated and ignored by Git; do not edit manually.                                                                                                                                |

Flow: typed/structured/attachment/visual input -> bounded source-context
normalization -> model-authored gate/subtask/mini-step reconciliation ->
workspace/session-scoped durable mutation -> canonical session snapshot and
hierarchy-aware history -> lightweight workspace index refresh.
