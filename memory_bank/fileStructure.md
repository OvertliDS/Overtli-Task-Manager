# File Structure Knowledge Base

## Concurrent route state

| Path                                                  | Responsibility                                                                                                | Invariants                                                                                                                                                                                                                          |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/core/session-scope.mjs`                          | Resolves one consistent payload/environment root-session identity and stable hashed session keys.             | Conflicting identity claims fail before route state is read or changed.                                                                                                                                                             |
| `src/core/planner.mjs`                                | Conservatively preserves explicit outlines and exposes non-completable fallback review scaffolds.             | Major outline roots become gates, depth-two children become internal subtasks, deeper items become mini-steps; model owns semantic domain content.                                                                                  |
| `src/core/source-context.mjs`                         | Normalizes bounded typed/pasted, structured, attachment/OCR, and visual prompt sources.                       | Entries are redacted, provenance/path/revision tagged, digest-addressed, append-only across steering, and bounded to the shared context budget.                                                                                     |
| `src/core/manager.mjs`                                | Resolves root-session canonical routes across workspace aliases and coordinates guarded lifecycle operations. | The route's starting workspace remains primary; active user work wins over unrelated completed history; ambiguous legacy authority requires explicit same-session selection; source review and descendant evidence gate completion. |
| `src/storage/sqlite-store.mjs`                        | Probes/repairs the native binding and provides the durable concurrent WAL store.                              | Only genuine ABI mismatch may trigger one package-local locked rebuild; schema v5 stores root-session bindings atomically with route creation and preserves pre-migration recovery copies.                                          |
| `src/storage/store.mjs`                               | Selects explicit SQLite/JSON or automatic native-first storage.                                               | Explicit SQLite fails closed; `auto` may fall back to JSON after probe/repair failure without deleting or overwriting inactive SQLite state.                                                                                        |
| `src/storage/json-store.mjs`                          | JSON fallback store and canonical binding persistence.                                                        | Every mutation holds `state.lock`; binding, route, checklist, and event creation are one transaction; stale locks older than 30 seconds may be recovered.                                                                           |
| `src/core/renderer.mjs`                               | Writes canonical hierarchy/source snapshots, summaries, and workspace-local indexes.                          | Session snapshots and summaries stay under the route's primary workspace; alias paths resolve to the same route.                                                                                                                    |
| `src/mcp/server.mjs`, `src/mcp/tools.mjs`             | Expose route tools and resources against the canonical manager resolver.                                      | Resource reads resolve through the root-session binding; names and argument schemas remain stable; no workspace `current.json` bypass selects another route.                                                                        |
| `src/mcp/schemas.mjs`                                 | Exposes bounded three-tier route, context, progress, and evidence contracts to models.                        | Model supplies domain-specific gates/subtasks/mini-steps; exact IDs and recursive evidence gates are explicit in tool guidance.                                                                                                     |
| `src/hooks/runner.mjs`                                | Resolves hook identity, appends prompt context, deduplicates invocations, and dispatches lifecycle handlers.  | Hooks without session identity do not touch route state; source review and descendant evidence gate Stop; completed canonical Stop reuses validated evidence; repeat guards remain intact.                                          |
| `src/install/agent-block.mjs`                         | Builds and safely patches OTM's marker-delimited root `AGENTS.md` protocol.                                   | Preserves all non-OTM text; duplicate/incomplete markers fail closed; generated guidance defines accumulated-context review and the three-tier model/OTM ownership boundary.                                                        |
| `AGENTS.md`                                           | Root repository guidance plus OTM's managed execution protocol.                                               | Repository guidance outside OTM markers is maintained manually; only the marker-delimited block is hook-managed.                                                                                                                    |
| `src/cli/commands.mjs`                                | Exposes install, diagnostics, snapshots, cleanup, and maintenance.                                            | Session-sensitive read/clear commands accept `--session-id`; doctor/snapshot are read-only.                                                                                                                                         |
| `.codex/overtli-task-manager/sessions/<session-key>/` | Runtime route state and session-owned scratch evidence.                                                       | Generated and ignored by Git; do not edit manually.                                                                                                                                                                                 |

Flow: root Codex session -> atomic canonical binding -> primary workspace and
persisted aliases -> bounded source-context normalization -> model-authored
gate/subtask/mini-step reconciliation -> hierarchy-aware history and summary ->
lightweight workspace-local index refresh.
