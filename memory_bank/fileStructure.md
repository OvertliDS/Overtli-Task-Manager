# File Structure Knowledge Base

- `src/core/shared-history.mjs` owns compact same-user history pages and exact
  saved-summary text chunks for Claude tools and the Codex CLI. It reads the
  canonical store without claiming routes or copying provider summaries.
- `createTaskManager().bindCodexOwner` is an internal native-host boundary:
  authentic original session, exact revision and canonical-binding CAS are
  required before a legacy route receives provider provenance and activity.
  It is not a model-facing MCP tool and does not settle host jobs.

## Concurrent route state

| Path                                                  | Responsibility                                                                                                | Invariants                                                                                                                                                                                                                          |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/core/session-scope.mjs`                          | Resolves one consistent payload/environment root-session identity and stable hashed session keys.             | Conflicting identity claims fail before route state is read or changed.                                                                                                                                                             |
| `src/core/planner.mjs`                                | Conservatively preserves explicit outlines and exposes non-completable fallback review scaffolds.             | Major outline roots become gates, depth-two children become internal subtasks, deeper items become mini-steps; model owns semantic domain content.                                                                                  |
| `src/core/source-context.mjs`                         | Normalizes bounded typed/pasted, structured, attachment/OCR, and visual prompt sources.                       | Entries are redacted, provenance/path/revision tagged, digest-addressed, append-only across steering, and bounded to the shared context budget.                                                                                     |
| `src/core/manager.mjs`                                | Resolves root-session canonical routes across workspace aliases and coordinates guarded lifecycle operations. | The route's starting workspace remains primary; active user work wins over unrelated completed history; ambiguous legacy authority requires explicit same-session selection; source review and descendant evidence gate completion. |
| `src/storage/sqlite-store.mjs`                        | Probes/repairs the native binding and provides the durable concurrent WAL store.                              | Only genuine ABI mismatch may trigger one package-local locked rebuild; schema v5 stores root-session bindings atomically with route creation and preserves pre-migration recovery copies.                                          |
| `src/storage/store.mjs`                               | Selects explicit SQLite/JSON or automatic native-first storage.                                               | Explicit SQLite fails closed; `auto` may fall back to JSON after probe/repair failure without deleting or overwriting inactive SQLite state.                                                                                        |
| `src/storage/json-store.mjs`                          | JSON fallback store and canonical binding persistence.                                                        | Every mutation holds `state.lock`; binding, route, checklist, and event creation are one transaction; stale locks older than 30 seconds may be recovered.                                                                           |
| `src/core/renderer.mjs`                               | Writes canonical hierarchy/source snapshots, summaries, and workspace-local indexes.                          | Session snapshots and summaries stay under the route's primary workspace; alias paths resolve to the same route.                                                                                                                    |
| `src/mcp/server.mjs`, `src/mcp/tools.mjs`             | Expose route tools and resources against the canonical manager resolver.                                      | Resource reads resolve through the root-session binding; names and argument schemas remain stable; no workspace `current.json` bypass selects another route.                                                                        |
| `src/mcp/schemas.mjs`                                 | Exposes bounded three-tier route, context, progress, and evidence contracts to models.                        | Model supplies domain-specific gates/subtasks/mini-steps; exact IDs and recursive evidence gates are explicit in tool guidance.                                                                                                     |
| `src/hooks/runner.mjs`                                | Resolves hook identity, appends prompt context, deduplicates invocations, and dispatches lifecycle handlers.  | Codex observes official SessionStart and Pre/PostToolUse/SubagentStart/SubagentStop events even without a route; pre-dispatch activity is durable, supported ODC mutations fail closed without a durable intent, and native subagents stay open until their exact agent_id stop. Compact hooks checkpoint/restore canonical state and never settle host work or transfer route ownership. |
| `src/install/agent-block.mjs`                         | Builds and safely patches OTM's marker-delimited root `AGENTS.md` protocol.                                   | Preserves all non-OTM text; duplicate/incomplete markers fail closed; generated guidance defines accumulated-context review and the three-tier model/OTM ownership boundary.                                                        |
| `AGENTS.md`                                           | Root repository guidance plus OTM's managed execution protocol.                                               | Repository guidance outside OTM markers is maintained manually; only the marker-delimited block is hook-managed.                                                                                                                    |
| `src/cli/commands.mjs`                                | Exposes install, diagnostics, shared cross-provider reads/continuation, snapshots, cleanup, and maintenance.  | `shared-history` and `shared-task` hide native owner IDs; `continue-task` requires trusted `CODEX_THREAD_ID`, exact expected revision, and configured host inspection, and rejects `--session-id`.                                      |
| `src/install/hook-config.mjs`, `hooks/hooks.json`    | Installs Codex lifecycle and tool hooks without removing unrelated handlers.                                  | Pre/Post tool matchers cover every supported local tool; official subagent start/stop hooks pair native child work. Claude lifecycle settings use the separate atomic user-settings installer.                                      |
| `.codex/overtli-task-manager/sessions/<session-key>/` | Runtime route state and session-owned scratch evidence.                                                       | Generated and ignored by Git; do not edit manually.                                                                                                                                                                                 |

Flow: root Codex session -> atomic canonical binding -> primary workspace and
persisted aliases -> bounded source-context normalization -> model-authored
gate/subtask/mini-step reconciliation -> hierarchy-aware history and summary ->
lightweight workspace-local index refresh.

## Shared provider continuation and Claude integration

| Path                                                       | Responsibility                                                                                      | Invariants                                                                                                                                                                                   |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/core/provider-session.mjs`                            | Maps trusted Codex/Claude session identities to the provider-neutral route session contract.         | Codex identity remains compatible; Claude gets a separate opaque session namespace; provider and session authority never come from a Claude MCP tool argument.                                 |
| `src/core/provider-adapter.mjs`                            | Binds lifecycle calls to one provider session and exposes canonical shared reads, owner-work inspection, and continuation.  | Read-only history can span providers; owner mutations are session-bound; transfer is explicit, evidence-gated, atomic, and revision-fenced in both directions; local Claude Stop uses a full exact-owner inspection without the transfer idle cutoff. |
| `src/core/continuation.mjs`                                | Validates complete recent owner activity and trusted host-liveness evidence before transfer.          | Event history truncation, missing/unknown sources, active work, stale evidence, or owner mismatch all deny transfer; native broker and ODC jobs are required sources; task-owned claims stay inside broker proof. |
| `src/claude/mcp-server.mjs`, `bin/otm-claude-mcp.mjs`       | Adds a native Claude stdio server over the existing canonical store and manager.                     | Every call requires a short-lived hook-issued workspace-bound capability; server does not import/alter the Codex MCP server or accept caller-supplied provider/session IDs.                   |
| `src/core/claude-capability.mjs`                           | Issues and verifies the encrypted, HMAC-signed Claude session capability.                            | Tokens are not task evidence, logs, or summaries; key file ACL is restricted and verified on Windows and mode 0600 is set on POSIX.                                                          |
| `hooks/claude-code.mjs`                                    | Observes all eleven supported Claude lifecycle events and drives shared route context/Stop handling. | Stop blocks on missing/incomplete owner coverage, active or unknown native-broker/ODC work, and unmatched host receipts; its loop guard precedes fallible work. PreCompact writes a route checkpoint; compact SessionStart injects route context; PostCompact never imports native transcript summary text or settles host work. |
| `src/install/claude-settings.mjs`, `scripts/install-claude-hooks.mjs` | Atomically merges the OTM hook set into supported Claude user settings.                    | Preserves unrelated settings and hooks; dry run, managed-entry idempotency, same-directory backup/hash checks, atomic replacement, and compare-before-rollback protect user configuration.      |
| `tests/claude-shared-continuation.test.mjs`, `tests/provider-adapter.test.mjs`, `tests/hooks.test.mjs` | Covers cross-provider route visibility, transfer evidence/CAS, both compact lifecycles, capability, installer, and exact Codex/Claude Stop owner-work gates. | Fixture payloads validate source contracts only; root-owned live host evidence, Claude CLI, active registration, and settings installation remain separate acceptance. |

Provider flow: Codex/Claude native identity -> same workspace-scoped OTM run,
event history, and summary store -> provider-specific live owner -> explicit
continuation only after recent activity and all trusted host work sources are
complete -> atomic owner-binding transfer and route-revision fencing.
